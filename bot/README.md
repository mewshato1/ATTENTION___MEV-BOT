# MEV Bot — BNB Chain Arbitrage

Арбитражный бот для BNB Chain (BSC). Ищет разницу цен между DEX
(PancakeSwap, BiSwap, ApeSwap) и исполняет прибыльные сделки.

---

## Структура проекта

```
mev_bot/
├── main.py          # Главный цикл бота (точка входа)
├── config.py        # Все настройки и константы
├── abi.py           # ABI контрактов (PancakeSwap, ERC-20)
├── chain.py         # Подключение к BSC, газ, баланс
├── dex.py           # Чтение цен из DEX-контрактов
├── arbitrage.py     # Логика поиска арбитража
├── executor.py      # Отправка транзакций
├── logger.py        # Цветной логгер
├── requirements.txt # Зависимости Python
└── .env.example     # Пример файла конфигурации
```

## Установка

### 1. Установи Python 3.10+

### 2. Установи зависимости
```bash
pip install -r requirements.txt
```

### 3. Настрой конфигурацию
```bash
cp .env.example .env
# Открой .env и заполни WALLET_ADDRESS, PRIVATE_KEY, RPC
```

## Запуск

### Проверка подключения
```bash
python main.py --check
```
Подключается к BSC, показывает текущий блок и баланс кошелька. Ничего не делает.

### Режим сканирования (безопасный старт)
```bash
python main.py --scan-only
```
Сканирует пары и показывает найденные возможности в терминале.
Транзакции НЕ отправляются. Используй для проверки логики.

### Один цикл
```bash
python main.py --once
```
Выполняет один цикл сканирования и исполнения, затем выходит.
Полезно для тестирования.

### Полный запуск (с DRY_RUN=true)
```bash
python main.py
```
Запускает бесконечный цикл. В режиме DRY_RUN транзакции симулируются —
реальных денег не тратится.

### Боевой режим
Только когда убедился что всё работает в DRY_RUN:
1. В файле .env поставь `DRY_RUN=false`
2. Убедись что на кошельке есть BNB (минимум 0.1 BNB на газ + сумма для торговли)
3. Запусти `python main.py`

## Важные ограничения текущей версии

**Два свапа НЕ атомарны.** Между первым и вторым свапом цена может измениться.
Следующий шаг — написать смарт-контракт на Solidity, который делает оба свапа
атомарно (или откатывает всё если прибыли нет).

**Нет мониторинга мемпула.** Бот реагирует на уже подтверждённые цены, а не на
pending транзакции. Для sandwich-стратегии нужен WebSocket + подписка на мемпул.

**Публичный RPC медленный.** Для конкурентной работы нужен платный RPC
(QuickNode, Alchemy) или собственная нода.

## Безопасность

- Используй ТОЛЬКО отдельный hot wallet с небольшой суммой
- Никогда не коммить .env в git (добавь в .gitignore)
- Начинай с MIN_PROFIT_BNB=0.003 чтобы не торговать в убыток
- Протестируй несколько дней в DRY_RUN прежде чем переключать на боевой режим
